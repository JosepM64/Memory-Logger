Auditor de rendimiento PRO: memoria, tiempo, CPU, SQL, DB, plugins, errores y cache.

== Description ==

Dashboard live, estadísticas históricas (Chart.js), diagnóstico bajo demanda con score 0-100, análisis de plugins, errores unificados (2h/200 líneas), integridad core, base de datos, recomendaciones hosting, análisis de cache (WP Rocket + SG Optimizer) y exportación JSON/HTML/TXT/CSV.

Ligero por diseño: muestreo, transients (errores 15min, cache 12h) y un solo scan por reporte.

== Installation ==

1. Sube `memory-logger-pro` a `wp-content/plugins/`.
2. Activa en Plugins.
3. Abre Memory Logger Pro.
