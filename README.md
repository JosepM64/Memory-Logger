# Memory-Logger
Plugin de WordPress para auditar el rendimiento de tu sitio: memoria, tiempo de carga, CPU, consultas SQL, tamaño de página y detección de bots. Incluye gráficos (Chart.js), estadísticas históricas, diagnóstico del servidor, análisis de plugins y exportación de informes. Diseñado para ser ligero: usa muestreo, caché y límites de registro.
